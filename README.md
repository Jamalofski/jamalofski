I'm a software architect in Bordeaux, France. This account holds the integrations and SDKs of two APIs I build and run.

## conv2pdf

[conv2pdf](https://conv2pdf.com/en/api/) converts Office documents, images and e-books to PDF, and merges, compresses and protects PDFs. Files are processed on servers in the EU (France) and deleted after one hour, or after 72 hours when a conversion fails.

- [conv2pdf-mcp](https://github.com/jamalofski/conv2pdf-mcp), MCP server for AI assistants
- [n8n-nodes-conv2pdf](https://github.com/jamalofski/n8n-nodes-conv2pdf), n8n node
- [zapier-conv2pdf](https://github.com/jamalofski/zapier-conv2pdf), Zapier integration
- [make-conv2pdf](https://github.com/jamalofski/make-conv2pdf), Make app
- [conv2pdf-php](https://github.com/jamalofski/conv2pdf-php), PHP SDK

## MailProbe

[MailProbe](https://mailprobe.dev) checks whether an email address exists and can receive mail, without sending anything to it. Addresses sent to the API are processed in real time on servers in the EU (France) and are not stored.

- [mailprobe-mcp](https://github.com/jamalofski/mailprobe-mcp), MCP server and Claude Code plugin
- [n8n-nodes-mailprobe](https://github.com/jamalofski/n8n-nodes-mailprobe), n8n node
- [zapier-mailprobe](https://github.com/jamalofski/zapier-mailprobe), Zapier integration
- [make-mailprobe](https://github.com/jamalofski/make-mailprobe), Make app
