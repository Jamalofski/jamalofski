This account holds the integrations and SDKs of Conv2pdf and a few other open-source tools; PDFKiln and MailProbe have their own organizations, [pdfkiln](https://github.com/pdfkiln) and [MailProbe](https://github.com/MailProbe).

## PDFKiln

PDFKiln is a drop-in replacement for wkhtmltopdf, which is archived: the same command line, so pdfkit, knp-snappy, laravel-snappy, wicked_pdf and Rotativa keep working unchanged, on a current Chromium with its sandbox on. MIT license.

[pdfkiln.org](https://pdfkiln.org) · [Migration guides](https://pdfkiln.org/migrate/)

- [pdfkiln](https://github.com/pdfkiln/pdfkiln), the program and its packages: APT (Debian, Ubuntu), Windows installer, winget, Docker, npm
- [setup](https://github.com/pdfkiln/setup), GitHub Action
- [php](https://github.com/pdfkiln/php), Composer package
- [homebrew-tap](https://github.com/pdfkiln/homebrew-tap), Homebrew tap
- [scoop](https://github.com/pdfkiln/scoop), Scoop bucket

## Conv2pdf

Conv2pdf is a PDF API with 19 tools: it converts Office documents, images, e-books and web pages to PDF, and PDFs to Word or images, and merges, splits, compresses and protects PDFs. Files are processed on servers in the EU (France) and deleted after one hour, or after 72 hours when a conversion fails.

[conv2pdf.com](https://conv2pdf.com/en/) · [API](https://conv2pdf.com/en/api/)

- [conv2pdf-mcp](https://github.com/jamalofski/conv2pdf-mcp), MCP server and Claude Code plugin
- [n8n-nodes-conv2pdf](https://github.com/jamalofski/n8n-nodes-conv2pdf), n8n node
- [zapier-conv2pdf](https://github.com/jamalofski/zapier-conv2pdf), Zapier integration
- [make-conv2pdf](https://github.com/jamalofski/make-conv2pdf), Make app
- [conv2pdf-php](https://github.com/jamalofski/conv2pdf-php), PHP SDK

## MailProbe

MailProbe checks whether an email address exists and can receive mail, without sending anything to it. Addresses are processed in real time on servers in the EU (France) and are not stored.

[mailprobe.dev](https://mailprobe.dev) · [API](https://mailprobe.dev/api-docs/)

- [mcp](https://github.com/MailProbe/mcp), MCP server and Claude Code plugin
- [n8n](https://github.com/MailProbe/n8n), n8n node
- [zapier](https://github.com/MailProbe/zapier), Zapier integration
- [make](https://github.com/MailProbe/make), Make app
- [wordpress](https://github.com/MailProbe/wordpress), WordPress and WooCommerce plugin
